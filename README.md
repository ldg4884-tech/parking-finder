# Parking Finder

안드로이드 주차 위치 자동 기록 앱.

## 제품 방향
- 차량 주행 후 정차/주차 상태를 감지하고 위치를 자동 저장
- 주차장 층별 도면을 자동으로 찾거나 이미지/PDF로 직접 등록
- 실내 위치 보정 후 도면의 실제 주차면에 차량 마커 표시
- 주차 이력과 차량 찾기 제공

## 기술적 원칙
GPS 단독으로 실내 주차면을 정확히 특정할 수 없다. GPS는 주차장 진입/이탈 및 대략적 위치 판단에 사용하고, 실내 주차면 수준의 자동 위치 판별은 BLE 비콘, Wi-Fi RTT, UWB 또는 주차장 시스템 연동 등 현장 인프라와 보정 데이터가 필요하다. 앱은 추정 위치와 확인된 위치를 명확히 구분한다.

## 단계
1. Android 앱 기본 구조 및 위치 저장 화면
2. 주행/정차 감지와 백그라운드 자동 기록
3. 도면 이미지/PDF 등록 및 층별 관리
4. 도면 자동 확보 후보 탐색 및 출처/사용권 확인
5. 도면 좌표 보정과 실내 위치 추정 연동
6. 주차 이력, 알림, 차량 찾기 및 현장 테스트

## Build
GitHub Actions에서 gradle assembleDebug 실행.
